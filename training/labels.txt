# One class name per line. Order defines the class index used by the model, the
# detector and the overlay, so it MUST stay in step with LABELS in
# scripts/prepare_dataset.py (test_dataset_prep.py fails if they drift) and with
# num_classes in configs/yolox_nano_seagrass.py. Lines starting with '#' are
# ignored by the detector.
#
# This list is what public underwater detection data actually provides — RUOD
# (13k images, marine life + divers) and TrashCan (7k images, debris) — rather
# than a wishlist. Every entry below can be trained today without annotating
# anything by hand.
#
# NOT here, deliberately:
#
#   seagrass, kelp, rocky seabed — continuous ground cover, not discrete
#   objects. A box round them has no defensible edges: where does one kelp end?
#   That is why nobody publishes box labels for them, and why the seagrass
#   literature (DeepSeagrass; "Image Labels Are All You Need for Coarse Seagrass
#   Segmentation", WACV 2024) uses patch classification or segmentation instead.
#   Seabed cover wants a second model with a different inference path.
#
#   inflatables, buoys — genuinely discrete and perfectly detectable, just
#   absent from every public underwater set. These need your own dive footage.
#   Add them here, retrain, and bump num_classes; nothing else changes.
#
# `trash` deliberately absorbs all of TrashCan's subcategories (trash_bottle,
# trash_fishing_gear, trash_plastic, and the rest). Those distinctions are finer
# than a nano model can hold, and "there is debris here" is the actionable fact.
